# JdiCLaw Setup 企业化裁剪清单

## 目标

将当前偏通用产品的 Setup 向导改造成更适合企业内部产品 `JdiCLaw` 的首次启动流程。

## 新流程

1. 欢迎使用
2. 企业身份准备
3. 产品化自检
4. 完成进入

## 裁剪原则

- 保留首次启动向导结构
- 移除首次启动阶段的模型服务配置
- 移除首次启动阶段的通用技能安装流程展示
- 保留运行时自检能力，但改成产品化表达
- 企业身份步骤先做默认通过，并保留 TODO 占位

## 改造项

### 1. 步骤调整

- 删除 `provider` 步骤
- 删除 `installing` 步骤
- 新增 `identity` 步骤
- 保留 `welcome`、`runtime`、`complete`

### 2. 文案替换

- Welcome 改为企业产品介绍
- Runtime 改为“JdiCLaw 工作台初始化”
- Complete 改为进入主界面前的企业版完成态
- 明确模型服务后续在设置页面内配置

### 3. 产品化自检

将原来的底层检查项包装为用户更易理解的三项：

- 核心服务
- 智能体引擎
- 本地工作台环境

### 4. 企业身份准备

- 默认通过
- 用简短说明提示企业身份能力后续会接入
- 明确保留 TODO 占位，便于后续接 SSO / 身份绑定

### 5. 导航调整

- 移除 Setup 中的“跳过设置”心智
- 保持“上一步 / 下一步 / 开始使用”

## 本次实施范围

- `src/pages/Setup/index.tsx`
- `src/i18n/locales/zh/setup.json`
- `src/i18n/locales/en/setup.json`
- `src/i18n/locales/ja/setup.json`

## 验收标准

- Setup 只剩 4 个步骤
- 首次启动不再出现模型服务配置界面
- 用户能看到企业身份准备占位步骤
- 自检页面不再直接暴露 Node.js / OpenClaw / Gateway 术语为主标题
- 完成页明确说明模型服务可在设置页面单独配置
